<div align="center">

Auth           →  JWT · HttpOnly · token versioning · session invalidation
Webhooks       →  HMAC-SHA256 · timing-safe comparison
Database       →  Parameterized queries · zero SQL injection surface
Rate Limiting  →  Tiered per endpoint & role
