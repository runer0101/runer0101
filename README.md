## Security Engineering

Security isn't a separate interest — it's embedded in how I build:

- **Auth**: JWT in HttpOnly cookies, token versioning for real session invalidation
- **Webhooks**: HMAC-SHA256 verification with timing-safe comparison
- **Database**: Parameterized queries — zero SQL injection surface
- **Rate Limiting**: Tiered limits per endpoint and per role
- **Access Control**: RBAC with granular permission overrides
- **Headers**: Helmet, CORS restricted, CSRF protection
